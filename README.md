# Sales Analytics Project

## Project Overview

This project analyzes sales data using Python and SQL to identify
sales trends, profitable products, regional performance, and
overall business performance.

The project demonstrates practical Data Analyst skills including
data analysis, SQL queries, data visualization, and business insights.

---

## Project Objectives

- Calculate total sales and total profit
- Analyze sales performance by product
- Analyze sales performance by region
- Identify the most profitable products
- Analyze monthly sales trends
- Calculate profit margin
- Identify top-performing orders
- Create visualizations from sales data

---

## Analysis Performed

### Sales Analysis

The Python program calculates:

- Total sales
- Total profit
- Total quantity sold
- Average order value
- Profit margin

### Product Analysis

The project identifies:

- Best-selling product
- Most profitable product
- Product-wise sales
- Product-wise profit
- Product-wise quantity sold

### Regional Analysis

The project analyzes:

- Sales by region
- Profit by region
- Best-performing region

### Monthly Analysis

The project analyzes:

- Monthly sales
- Monthly profit
- Best sales month
- Most profitable month

---

## Data Visualization

1. Sales by Product
